# 工程格式、API 与维护

## 工程数据

工程 JSON 的 schema 为 made-project-3。faces 数组顺序就是展开组内顺序。每面有唯一 id、底端原点 origin=[X,Y,Z]（毫米，Y 向上）、azimuth（从世界 +X 朝 +Z 的角度）、spans（各实际跨）、可选 floors（自下而上）、parapet（计入最上段的饰面高度）、group（连续组）、outline（本面上缘左起 U 向右、V 向下）、features。背板是否存在、实洞及遮挡分别建模。surfaceTriangles 可以输入实测墙网格投影三角形，并集为材料域。输入分区与计算规模受实现上限约束；曲面、非立面或未标注的构件先经设计师分解。标定后的原始模型定位存于 model.transform，展示缩放不参与排板计量。

设计条件可从「詳細条件 JSON を編集」完整编辑。锁定完成功能可在板检查器点击“仕上を固定”；locks 对应原板 ID，清除该键可解锁。blankCols 为显式留白列（0 起算），缺省走三步求解；mirrorBits 控制逆向扫描时内部位图翻转。多面连续要求实际相邻，雁行投影例外用 projectionEvidence 留存设计判断。返面、凹位、主角和不可见面由人员标注。roof/parapet 归属及异顶高的上缘对齐须与已批准立面对照。

设计材料规则中 catalog[color] 为日铁横/竖、淀钢横/竖、IG 横/竖六个位置；缺号为 null。fabrication[color] 含 maxLength、fold、kerf（mm）、wastePct、pack 和 confirmed。批准尺寸后按切割方向分段，统计包络毛料及备料取整；复杂加工由厂家复核，未确认时列“要深化”。prices 是项目确认的圆/平方米，budget 是项目总上限。可用「単価・加工・予算条件」编辑。光泽/明度不能从 RGB 还原，landscape.colorLimits 支持以仕上为键的 hues、minValue、maxValue、maxChroma；approvedSamples 记录对应 hue、value、chroma 和 source。面积分母 net 为施工净面积、visible 为扣除遮挡后可见面积。地区条件和产品有效期应由负责人员在版本说明中明确。色相类别的边界需写成批准的枚举。

results.pieces 记录物理原板 panel、绘图分片 id、局部多边形、饰面、面积 mm²、是否遮挡及 trace。seams 消去纯三角剖分和裁片内部边；trims 与 labels 独立于饰面面量。XLSX 分开表示几何图形片、下料件及采购参考量。每个导出携带 resultId，可查 revision、源图、批准证据和任务编号。DXF 模型空间为 mm，GLB 为 m，工程 GLB 交付饰面几何；原建筑模型和合成输入随委托资产交接。色样及 HDR/PBR 最终渲染以批准材质与专业 CG 校样为准。

旧版排板 JSON 通过 migrate 转成草稿，保留原字段和复核状态，分配矩形开口、连续面、银色标识区、余白列和全宽连窗。旧自由图案作为原始格网参考保留，可以查看原案。工程 JSON 可离线传送参数；模型、原图资产与审核历史完整移交请使用备份或 CG 任务包。创建分支使用「保存した版から案件を複製」，原案件文件引用会复制到新的权限域。

## 服务

HTTP 前缀 /api/made/v1/。POST 使用 JSON 及 X-Made-Request: 1；本地界面使用同源会话。核心接口为 new、projects、project、revision、solve、save（expectedRevision）、review、fork、file、asset、job、jobStatus、download、policy、policies、member、login、logout、ai 和 migrate。版本冲突返回 409，输入错误 422，权限错误 403。job 以项目/版/格式/参数去重；CG 每个版本返回同一订单号。任务在服务重启后重新调度。规则求解区分可行、固定方案冲突与有限搜索未找到方案，搜索失败后可打开原批准版。任务失败会显示原因，失败或取消可从任务台重试。

数据库 private/made.sqlite 管理项目、修订、账号、成员、会话、规则主数据、任务和审计；文件按 SHA-256 存储。技术栈为 Python 标准库和 SQLite，现有 Python/MySQL/Nginx 无需升级，新程序不连接现有业务数据库。团队多人模式提供本应用账号和项目授权。已有企业 IdP 的 SSO、邮件系统、ERP/厂商自动订货是组织集成点；需要真实协议与部署授权。当前委托采用项目内的 CG 任务台。项目文件不位于可静态访问的 web/ 内。

可选自有网关在 private/gateway.json 内设置 {"approved":true,"textUrl":"https://网关/文字路径","imageUrl":"https://网关/图像路径","token":"由管理员填写"}，限制文件权限到拥有者。文字请求含 intent、meaning、allowedWaves，返回 narrative、mode、wave；图像请求使用四张同坐标系的 1536×1024 PNG data URL。composite 是已对位的建筑与现场照片，background 是现场照片，depth 是近亮远暗的建筑深度，mask 的不透明区域保护建筑和前景。intent 和 environment 指定设计意图和时间带。网关须返回同尺寸的 image（PNG data URL），客户端裁去适配边距并重新覆盖原始建筑和前景。内置商业适配器支持 OpenAI Responses 和 Image Edits，两者独立选择模型；留存条件、调用权限、限额、延时须以客户账号实测和合同为准。外发关闭时仍可使用离线求解、本地图像融合和说明。正式运维应单独验证网关日志策略、备份和存储保留期。

## 复核与业务指标

「実案件の工数・費用を比較」以本案人工和系统工时、人工单价、外注费用、周期、运行费用与初期投资计算节省和回收件数。系统没有赋予 1 秒排板、15 秒 AI 出图、固定节省率或 3–5 案回本默认实绩。管理层正式数据须使用同一工程修订单试用后录入。
