**测试记录。** 标准库测试 21 项，其中包括真实回环 HTTP 请求和两个组织用户的审核场景。2.0 原 ZIP 指纹与评审稿一致，在临时目录运行 core、rendering、validate-building 及后端两项测试。新版用例分别复现了超序列长度的租户首排、重叠洞口、局部连窗和多阶段交叉，在并发重复导出测试中修复了临时文件竞争。新版实际工程输出数字见 building01-validation.json，数据随模型和规则版本一起解释。DXF 以 ezdxf 重新打开、检查单位和实体；XLSX 以 openpyxl 读回表名及结果标识；GLB 检查文件长度、坐标边界和结果标识。

**尚未完成的验收。** 当前执行环境禁止 Chromium 使用所需的本地 socket，未获得自动浏览器图形端到端通过记录，也未在客户 Mac/iPad、AutoCAD 或供应商生产账号上实测。selftest.html 提供在目标端的同入口检查。C4/C6、镜像方向、标志净空、法定面积口径与真实案例的逐板签认，须由 GLP、设计单位、采购共同确认。本包不含这些签字记录，也未验证所有规则均获 GLP 认可或在全部输入下零误差。

**适用边界。** 固定主角及雁行的连续投影依赖输入的面序与判断依据；自由 FBX 网格不会自动推断消防窗、租户权属和工法。目视色差、远景艺术构图、复杂异形连接与厂家深化仍需复核。当前是回环服务＋独立 SQLite，企业环境须另做容量测试、HTTPS 配置和恢复演练。正式场景中的组织认证对接、电子签章、厂商实际采购和企业外部工单推送需客户提供协议；当前包内的组织账号、版本审批、三厂家量表和 CG 任务台可独立运行。图像外发只在采购、权限、端点与保留条件获准并在项目上启用后生效。

### 3.0.1 增量验收

同版 DXF 与三厂商 Excel 增加独立于 CG 发注的一键打包任务。服务测试经项目保存、任务创建、下载、包内 resultId 比对。对 building01 的 dry、cs 两种输入重新解析 DXF，并用 openpyxl 核对三厂商页净面积与割付分片合计；该样本特注比率分别约 16.10% 和 0%。以合成色块测试遮罩位置、建筑与前景像素锁定、环境替换和四张 PNG 的 multipart 字段与顺序。本次未在真实商业模型、真实空撮照片或 AutoCAD 桌面版中验收，未完成浏览器整机验收。原项目的 15 秒指标仍待实测。
